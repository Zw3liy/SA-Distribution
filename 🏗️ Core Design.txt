🏗️ Core Design
1. Agent Core
Handles:

Input/output loop in CMD

Connection to Claude/OpenAI APIs

Plugin dispatch (commands starting with :)

2. Plugin System
Each project defines its own plugins:

File management (:open, :save)

Git integration (:commit, :push)

Business logic (:invoice, :ticket)

Utilities (:search, :calc)

3. Configurable Backend
Switch between Claude or OpenAI easily:

backend="claude"

backend="openai"

4. Extra Features
Memory: Save conversation history in JSON

File Editing: Read/write project files

Command Execution: Run safe shell commands

Context Awareness: Load project-specific plugins dynamically
